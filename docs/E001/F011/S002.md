# S002 · el freno de aquas deja pasar memoria fijar

[Inicio](../../README.md) › [E001](../README.md) › [F011](README.md) › S002

Este [slice](../../glosario.md#slice) exenta del freno de llamadas la orden que exige el cierre.

## En una frase

`aquas memory set`, sola, pasa aunque el freno esté desbordado, y no cuenta.

## Para qué existe

**El problema.** `aquas budget` frena toda llamada al pasar su tope (E001/F015/S002). Eso incluye `aquas memory set`.

**Por qué importa.** El [hook](../../glosario.md#hook) de cierre pide la memoria al día. Con el freno activo, el [agente](../../glosario.md#agente) no puede cumplirlo.

**La solución.** Antes de contar, el freno mira el comando. Si es `memory set` suelta, la deja pasar.

**Contrato.**

| Regla | Valor |
|---|---|
| Qué pasa | herramienta Bash cuyo comando entero es `aquas memory set campo=valor…` |
| Binario | `aquas`, `go run ./cmd/aquas` o `./.tmp/aquas.exe`; entre comillas, solo la ruta del `.tmp/` de este repo |
| Cuenta | no suma al turno ni al tope de la feature |
| Cualquier otra cosa | otra orden, redirección, `&`, `$(`, `<(` o un binario ajeno se trata como cualquier comando |
| Otro comando | se cuenta y se frena igual que hoy |

**Casos borde.**

- `aquas memory show` no está exenta.
- Otra herramienta, como Edit, no está exenta.
- El aviso de contexto no cambia; con la orden exenta sale en la llamada siguiente.
- Un valor entre comillas puede llevar `;` o `|`; entre comillas dobles no puede llevar `$`.
- Se prefiere frenar de más. Se frenan una variable delante (`FOO=1 aquas …`) y una ruta absoluta sin comillas.
- También `go run ./cmd/aquas/` con barra final y un acento grave dentro de comillas dobles.
- La ruta del repo al estilo Git Bash (`/d/…`) entre comillas también se frena.
- Límite aceptado: las formas sin ruta absoluta (`aquas`, `./.tmp/aquas.exe`, `go run`) dependen de la carpeta y el PATH del shell.

## Analogía

Piensa en **la salida de emergencia de un cine lleno**.

- Nadie más entra, pero se puede salir.

Límite de la analogía: solo una orden exacta usa esa salida.
